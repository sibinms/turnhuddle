Privacy

Last updated 26 November 2026

Turnhuddle is a VS Code extension with no account, no server and no analytics. This page explains where your data goes when you use it.

What you type and what the agents reply

Your task and the conversation so far are sent to Claude and Codex through their official command-line tools, the Claude Code CLI and the Codex CLI, under the accounts you signed in to with those tools. Anthropic's and OpenAI's terms and data policies apply to that traffic. The CLIs may also keep their own session history on your machine.

What Turnhuddle stores

  • Each conversation is a JSON file in VS Code's storage folder for the extension, on your machine. Archiving marks a file; it never deletes one. Turnhuddle: Reveal History Folder shows where they are.
  • The text of each conversation is also written to the Turnhuddle Output channel for the current VS Code session.
  • To continue a CLI session, Turnhuddle reads the CLIs' own transcript files on your machine, only to list them.

Network requests Turnhuddle makes itself

Only one: when update checks are on, it asks GitHub for the latest release of Turnhuddle, at most once a day and when you run Turnhuddle: Check for Updates. The request carries no information about you or your work. Turn it off with the turnhuddle.checkForUpdates setting.

Telemetry

None. Turnhuddle sends no usage data, crash reports or analytics.
